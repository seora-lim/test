한국 도서 시장 데이터를 시각화한 인텔리전스 대시보드입니다.

## 주요 기능

- **핵심 KPI 카드** — 총 판매 부수, 시장 규모, 전자책 점유율, 신규 발간 종수
- **매출 추이 차트** — 종이책 vs 전자책 월별/분기별 비교 (탭 전환)
- **장르별 판매 비중** — 도넛 차트 + 범례
- **종합 베스트셀러 Top 10** — 3사 종합 순위표
- **독자 연령대 분포** — 2025 vs 2026 비교 막대 차트
- **판매 채널 점유율** — 온라인/오프라인/구독/기관 채널 분석
- **장르별 성장률** — 전년 대비 성장률 막대 차트
- **핵심 인사이트** — 데이터 기반 출판 전략 추천
- **분기별 출판 전략 캘린더** — 레이더 차트 + 분기별 전략 카드

## 디렉토리 구조

```
book-insight/
├── public/
│   ├── index.html      ← HTML 골격 (Canvas 태그, 링크 포함)
│   ├── css/
│   │   └── style.css   ← 모든 스타일 (CSS 변수, 컴포넌트, 반응형, 애니메이션)
│   └── js/
│       └── charts.js   ← Chart.js 초기화 + switchTab 함수
├── server.js           ← Express 서버 (정적 파일 서빙)
├── package.json        ← npm 메타데이터 + scripts
└── README.md
```

## 로컬 실행

```bash
# 의존성 설치
npm install

# 서버 시작
npm start
```

브라우저에서 http://localhost:3000 접속

## 개발 모드

파일 변경 시 자동 재시작:

```bash
npm run dev
```
